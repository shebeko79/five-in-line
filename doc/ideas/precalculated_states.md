### Предрасчитанное количество состояний.
Сейчас мы ставим фигуру, и заранее расчитываем где какие угрозы образуются.
По идее одна клетка, кроме себя, может влиять только на 8 (4 слева и 4 справа).
```text
⚫⚫⚫⚫🔴⚫⚫⚫⚫
```

8x 4(горизоталь, вертикаль и 2 диагонали) = 32 (33 если с самой клеткой)

```text
⚫⬜⬜⬜⚫⬜⬜⬜⚫
⬜⚫⬜⬜⚫⬜⬜⚫⬜
⬜⬜⚫⬜⚫⬜⚫⬜⬜
⬜⬜⬜⚫⚫⚫⬜⬜⬜
⚫⚫⚫⚫🔴⚫⚫⚫⚫
⬜⬜⬜⚫⚫⚫⬜⬜⬜
⬜⬜⚫⬜⚫⬜⚫⬜⬜
⬜⚫⬜⬜⚫⬜⬜⚫⬜
⚫⬜⬜⬜⚫⬜⬜⬜⚫
```

Ставя фигуру, логично было бы пересчитывать состояние только в окресности этой фигуры.
Можно заранее держать поле рассчитанных состояния.
И держать некий стек (32 струкутрки с того же поля), запоминая предыдущее состояние, а потом восстанавливать его, когда мы выходим.

```
struct state_to_5
{
  field_type; //(empty,krestik,nolik)
  int h[5];   // 
  int h[5];
  int tb[5];
  int bt[5];
};
```
по дефолту все поля 1 что означает, если вокруг пустота, то если сюда поставить будет 1 собранная из линии
0 - означает что невозможно собрать, потому что на линии есть фигуры другого цвета если 0 то мы не увеличиваем.
